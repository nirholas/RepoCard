How it works

Designed for your project, not a template

Other generators put every repo on the same card. RepoCard reads what your project is and art-directs a card to match.

Reads your repo

Description, README, topics, languages and license. The README is treated as data, never as instructions.

Designs four concepts

An LLM picks layout, palette, type and a one-line tagline from a curated design system, so every result stays tasteful and legible.

Renders at the edge

Code draws the final image on Cloudflare: real fonts, crisp text, no garbled AI lettering. Under 1 MB, exactly 1280×640.

FAQ

Questions, answered

Why can't RepoCard set the image on GitHub for me?

GitHub has no public API for the social preview, so every tool, RepoCard included, ends with an upload in the repo's settings. The RepoCard CLI automates that upload in your own browser session, so no credentials are ever shared with RepoCard.

Where is the image shown?

Anywhere your repository link is shared: X, LinkedIn, Slack, Discord, iMessage, Facebook and more. GitHub search results don't show it.

Which AI designs the cards?

By default an open model on Cloudflare Workers AI. Self-hosters can use any OpenAI-compatible endpoint (Groq, OpenRouter, Gemini, Ollama). If the model is unavailable, RepoCard falls back to deterministic designs, so you always get a card.

Does it work with private repositories?

No. The hosted service only reads public repositories through the GitHub API and never asks for access to your account.

Will my card change over time?

The design is generated once and stored, so it stays the same. Star and fork counts refresh every few hours. Click "New concepts" whenever you want fresh designs.

Can I host my own?

Yes. RepoCard is MIT licensed and deploys to Cloudflare Workers in a few minutes. See self-hosting.
