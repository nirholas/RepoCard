Bulk export

Cards for every repo you own

Enter a GitHub user or organization. RepoCard designs a card for each public repository, with one-click links to each repo's settings and a ZIP of everything.

Upload them all automatically CLI

GitHub has no API for social previews. The RepoCard CLI opens a browser window, you sign in to GitHub yourself, and it uploads each card for you. Your session never leaves your machine.

# dry run: shows what would change
npx repocard apply your-username

# apply, skipping repos that already have a custom preview
npx repocard apply your-username --yes
CLI guide

Doing it by hand 2 min/repo

  1. Download the ZIP above.
  2. Click Settings ↗ on a card to open that repo's settings.
  3. Under Social preview, choose Edit → Upload an image… and pick the matching PNG.

The ZIP includes index.html with every settings link in one place.
